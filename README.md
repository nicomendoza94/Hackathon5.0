# El Impostor en el Congreso (versión paraguaya)

Proyecto de videojuego desarrollado en Python + Pygame para hackathon.

## Descripción
Juego single-player con NPCs inspirado en el concepto de impostor,
ambientado en el Congreso paraguayo con tono humorístico.

## Roles
- 70% Ciudadano
- 30% Impostor

## Estado
Repositorio inicial con estructura y comentarios base.
